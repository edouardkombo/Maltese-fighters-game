🎙 Record the game's voices

Record each line with a real Maltese voice (yours, your friends', your family's). The game plays these recordings instead of the computer voice.

  1. Press Record, say the line with energy, press Stop. Listen with Play, redo if you like.
  2. Press Save on each line: it downloads a file (for example mela.webm).
  3. Press Download voices.json at the bottom.
  4. Put all those files in the game's public/voices/ folder and publish.

Lines you skip keep using the computer voice.
